**Sistem Administrasi Tugas**
Aplikasi manajemen tugas siswa berbasis web (Full-Stack).

1. Frontend (HTML5, CSS3): membangun struktur dan desain antarmuka menggunakan sistem kartu (custom grid), (Bootstrap 5): memastikan tampilan rapi dan responsif saat diakses melalui hp/laptop.
  
2. Backend (PHP Native): sebagai logika program dan penghubung utama antara tampilan frontend dengan database, (Session Management): mengatur sistem keamanan login untuk memvalidasi hak akses pengguna.

alur kerjanya (step-by-step)
- Development (VS Code + XAMPP): proses penulisan kode menggunakan vs code dan menjalankan server lokal menggunakan xampp untuk tahap pengujian.
- Database Management (MySQL): merancang dan mengelola tabel melalui phpmyadmin untuk menyimpan data siswa dan tugas secara terorganisir.
- Web Server (Apache): mesin utama untuk memproses dan menjalankan skrip PHP 
- Version Control & Backup (GitHub): menggunggah dan menyimpan seluruh riwayat file kode ke github agar aman.
- Deployment (Hosting InfinityFree): memindahkan semua file kode dan database ke  server infinityfree agar web dapat diakses secara publik melalui internet.
